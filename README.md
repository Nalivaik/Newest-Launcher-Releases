# Newest Launcher — загрузки

Публичные файлы доступны на странице [Releases](https://github.com/Nalivaik/Newest-Launcher-Releases/releases). Исходный код лаунчера хранится в отдельном приватном репозитории.

Первый выпуск будет помечен **TEST PREVIEW**. Это проверка сборки Windows x86-64: Shield включён, но в установщик добавлены подписанные тестовые заглушки вместо игрового клиента. Такая версия **не запускает Minecraft** и не является production-релизом. Тестовые ключи создаются на время сборки; production-ключи не используются.

Перед установкой сверяйте SHA-256 файла со значением в описании конкретного выпуска. Рабочий релиз появится отдельно после проверки настоящего подписанного клиента и Windows-запуска.
